Diese Dateien sind eine Referenzkopie der öffentlichen AUTOSAR Classic-Platform
Requirements-Spezifikation für das OS (RS_OS), gegliedert nach Kapiteln. RS_OS enthält
die High-Level-Requirements (SRS_Os_*), von denen die SWS_OS-Requirements (siehe
../sws_os/) abgeleitet sind — bessere Ausgangsbasis für die Requirements-Ableitung in
Issue #28 als SWS_OS allein. Dient ausschließlich der internen Referenz beim
Clean-Room-Entwurf von rOSEK, siehe PLAN.md.
