== 4.13 Configuration of Multi-Core systems

=== 4.13.1 Overview

This section contains high-level requirements on the system configuration with respect to Multi-Core.

=== 4.13.2 Requirements

[[SRS_Os_80008]]
It shall be a common OS configuration across multiple cores ⌈

....
    Description:    Disjunctive object IDs have to be generated, if objects are to be addressed
                    across cores.
                    If, e.g. tasks are activated across cores, IDs have to be unique across cores.
    Rationale:      This results in a common configuration and affects flashing/programming
                    strategies.
    Use Case:       Activating tasks or setting events across cores
                    OS specification
                    [SRS_Os_80001]
    Dependencies:
                    [SRS_Os_80015]
                    [SRS_Os_80016]
    Supporting      Multi-Core Concept document
    Material:
....
⌋
