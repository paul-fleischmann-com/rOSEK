== 4.14 Services in Multi-Core systems

=== 4.14.1 Overview

The following chapter defines a set of mechanisms / services that allow optimal usage of a Multi-Core environment. The services might be provided by different AUTOSAR

BSW modules. The AUTOSAR_SWS_Multi-Core defines from which module which service can be accessed.
