== 10.4 Containers and configuration parameters for ARTI

This section describes the structure (containers) and the parameters of ARTI objects related to the OS configuration. ARTI objects are defined by the MOD_ARTI model. For a detailed description of the referenced ARTI parameters, please see chapter 10 of [11]. Also refer to application note 12.7 of this document.
